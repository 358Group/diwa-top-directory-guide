How to Update Safely

  2. Save important transaction references.
  3. Download the new APK from the verified homepage.
  4. Confirm that the package ID matches the installed app.
  5. Compare the new checksum with the value on this page.
  6. Install the update over the existing version when the signature matches.
  7. Recheck permissions after updating.

Update Not Installing

A signature conflict, different package ID, incomplete download, low storage or unsupported Android version may block an update. Do not uninstall the working app or erase its data until recovery information is saved. Follow the APK troubleshooting guide.
